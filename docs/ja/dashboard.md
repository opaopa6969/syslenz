## 概要

ダッシュボードは syslenz のデフォルトビューです。システムの状態を1画面にまとめ、5秒以内にマシンの状況を把握できるよう設計されています。デフォルトで毎秒自動リフレッシュします（設定で変更可能）。

どのビューからでも `D` を押せばダッシュボードに戻れます。

## ダッシュボードセクション

ダッシュボードはセクションに分かれており、各セクションが主要なサブシステムを表します:

| セクション | データソース | 表示内容 |
|-----------|------------|---------|
| **ロード** | `loadavg`, `stat` | 1/5/15分ロードアベレージ、CPU数、ロード対コア比 |
| **メモリ** | `meminfo` | MemTotal、MemAvailable、MemFree、Cached、Buffers、使用率 |
| **CPU** | `stat` | 状態別内訳: user、system、idle、iowait、steal |
| **スワップ** | `meminfo`, `swaps` | SwapTotal、SwapFree、SwapUsed、使用率 |
| **ネットワーク** | `net/dev` | インターフェース別 RX/TX バイト数、パケット数、エラー、ドロップ |
| **ディスク** | `df`, `diskstats` | ルートファイルシステム使用率、ディスクI/O統計 |
| **プロセス** | `processes`, `stat` | 合計数、実行中、スリープ中、ゾンビ、D状態 |
| **稼働時間** | `uptime` | システム稼働時間（わかりやすい形式） |

## AAバーグラフ (v1.1.0)

v1.1.0 で、ダッシュボードの RAM、Swap、CPU セクションに ASCIIアートバーグラフが追加されました。使用率をブロック文字で視覚的に表示します:

```
RAM:  [████████████░░░░░░░░] 62%
Swap: [██░░░░░░░░░░░░░░░░░░]  8%
CPU:  [██████████████░░░░░░] 71%
```

`█` は使用中の割合、`░` は空き領域です。数値と組み合わせて表示されるため、リソースの消費状況をひと目で把握できます。

## スパークライングラフ (v1.1.0)

v1.1.0 で、ダッシュボードのロードとメモリセクションに、直近の履歴トレンドを示すスパークラインが追加されました:

```
Load:  ▁▂▃▄▅▆▇█▇▅▃▂▁▁▂▃▄▅▆
Memory: ▅▅▅▅▆▆▆▇▇▇▇▇▆▆▅▅▅▅▅▅
```

スパークラインは8段階のブロック文字 (`▁▂▃▄▅▆▇█`) を使い、リングバッファに蓄積されたスナップショット履歴からトレンドを描画します。自動リフレッシュが有効なら、スパークラインもリアルタイムで更新されます。

グラフビュー (`g`) に切り替えなくても、ダッシュボード上でメトリクスの推移を確認できます。

## セクションナビゲーション

ダッシュボードでの操作:

| キー | アクション |
|------|----------|
| `j` / `k` または 矢印キー上下 | 次/前のセクションを選択 |
| `Enter` | 選択セクションにドリルイン（クラシックモードへ） |
| `Tab` | 効果なし（ダッシュボードにサイドバーはない） |
| `D` | どのビューからでもダッシュボードに戻る |

選択中のセクションはハイライト表示されます。`Enter` を押すと、対応するデータソースが選択された状態でクラシックモードに切り替わります。

## 各メトリクスの見方

### ロードアベレージ

ロードアベレージは、実行キュー内のタスク数と割り込み不可I/O待ちのタスク数の平均です。3つの値はそれぞれ1分、5分、15分の平均を表します。

**読み方:**
- ロードをCPUコア数（ダッシュボードに表示）と比較する
- ロード < コア数: 余裕あり
- ロード = コア数: フル稼働だが過負荷ではない
- ロード > コア数: タスクがキューに溜まり、レスポンスが劣化
- ロード > コア数の2倍: 深刻な過負荷

### メモリ

ダッシュボードはメモリを絶対値とパーセンテージの両方で表示します。

**主要フィールド:**
- **MemTotal**: 搭載されている物理RAM合計
- **MemAvailable**: スワップなしでアプリが使えるメモリ（最も重要な値）
- **Cached**: ディスクキャッシュとして使われているRAM（回収可能）
- **Buffers**: ファイルシステムメタデータ用RAM（回収可能）

**読み方:**
- MemAvailable > MemTotalの20%: 健全
- MemAvailable 10-20%: 注意して監視
- MemAvailable < 10%: 危険、OOM Killerリスク

### CPU使用率

CPU時間のパーセンテージ内訳で表示します:

- **user**: アプリケーションコードの実行
- **system**: カーネルコードの実行
- **idle**: 何もしていない時間
- **iowait**: I/O完了待ちでCPUが空いている時間
- **steal**: ハイパーバイザに取られた時間（VMのみ）

**読み方:**
- userが高い: アプリがCPUバウンド
- iowaitが高い: ストレージがボトルネック（CPU自体の問題ではない）
- stealが高い: ホストがオーバーコミット、VM移行を検討

### ネットワーク

インターフェース別のトラフィック統計:

- **RX bytes / TX bytes**: 受信/送信データ量
- **RX packets / TX packets**: 受信/送信パケット数
- **RX errors / TX errors**: 受信/送信エラー（通常0であるべき）
- **RX drops / TX drops**: ドロップされたパケット（通常0であるべき）

エラーやドロップが0以外なら、ハードウェアの問題、ドライバのバグ、またはネットワーク輻輳が疑われます。

### ディスク

ルートファイルシステムの使用率とI/O統計:

- **使用率 %**: ルートファイルシステムの使用割合
- **読み取り/書き込み**: 完了したI/O操作

80%を超える使用率は要注意、90%を超えると危険です。

## 詳細へのドリルイン

セクションを選択して `Enter` を押すと、該当するデータソースが選択された状態でクラシックモードに切り替わります。例:

- **メモリ**を選択して Enter → `meminfo` が選択された状態で開く
- **ネットワーク**を選択 → `net/dev` が開く
- **ロード**を選択 → `loadavg` が開く

クラシックモードでは、各フィールドの詳細ビュー、差分ビュー、グラフにアクセスできます。`Backspace` でダッシュボードに戻れます。

## カスタマイズ

### リフレッシュ間隔

リフレッシュ間隔は `~/.config/syslenz/config.toml` で設定します:

```toml
[general]
interval_ms = 1000  # ミリ秒 (デフォルト: 1000)
```

実行中に `a` で自動リフレッシュのオン/オフ切り替え、`r` で手動リフレッシュもできます。

### デフォルトビュー

ダッシュボードの代わりにクラシックモードで起動するには:

```toml
[general]
default_view = "classic"
```

または `--classic` CLIフラグを使います。

### 言語

```toml
[general]
lang = "ja"  # "en" または "ja"
```
