## 概要

ダッシュボードは syslenz のデフォルトビューです。システムの健全性を1画面に要約し、5秒以内にマシンの状態を把握できるように設計されています。ダッシュボードはデフォルトで毎秒自動リフレッシュされます（設定変更可能）。

任意のビューから `D` を押すとダッシュボードに戻ります。

## ダッシュボードセクション

ダッシュボードはセクションに分かれ、各セクションが主要なサブシステムを表示します:

| セクション | データソース | 表示内容 |
|-----------|------------|---------|
| **ロード** | `loadavg`, `stat` | 1/5/15分ロードアベレージ、CPU数、ロード対コア比 |
| **メモリ** | `meminfo` | MemTotal、MemAvailable、MemFree、Cached、Buffers、使用率 |
| **CPU** | `stat` | 状態別内訳: user、system、idle、iowait、steal |
| **スワップ** | `meminfo`, `swaps` | SwapTotal、SwapFree、SwapUsed、使用率 |
| **ネットワーク** | `net/dev` | インターフェース別 RX/TX バイト数、パケット数、エラー、ドロップ |
| **ディスク** | `df`, `diskstats` | ルートファイルシステム使用率、ディスクI/O統計 |
| **プロセス** | `processes`, `stat` | 合計数、実行中、スリープ中、ゾンビ、D状態 |
| **稼働時間** | `uptime` | システム稼働時間（人間が読みやすい形式） |

## セクションナビゲーション

ダッシュボード表示での操作:

| キー | アクション |
|------|----------|
| `j` / `k` または 矢印キー上下 | 次/前のセクションを選択 |
| `Enter` | 選択セクションにドリルイン（クラシックモードに切替） |
| `Tab` | 効果なし（ダッシュボードにはサイドバーなし） |
| `D` | 任意のビューからダッシュボードに戻る |

現在選択中のセクションはハイライト表示されます。`Enter` を押すと、対応するデータソースが選択された状態でクラシックモードに切り替わります。

## 各メトリクスの理解

### ロードアベレージ

ロードアベレージは、実行キュー内のタスク数と割り込み不可I/O待ちのタスク数の平均を表します。3つの値はそれぞれ1分、5分、15分の平均です。

**読み方:**
- ロードをCPUコア数（ダッシュボードに表示）と比較
- ロード < コア数: システムに余裕あり
- ロード = コア数: フル稼働だが過負荷ではない
- ロード > コア数: タスクがキューに溜まっている、レスポンスタイムが劣化
- ロード > 2倍のコア数: 著しい過負荷

### メモリ

ダッシュボードはメモリを絶対値とパーセンテージの両方で表示します。

**主要フィールド:**
- **MemTotal**: インストールされた物理RAM合計
- **MemAvailable**: スワップなしでアプリケーションが利用可能なメモリ（最も重要な数値）
- **Cached**: ディスクキャッシュとして使用されているRAM（回収可能）
- **Buffers**: ファイルシステムメタデータ用RAM（回収可能）

**読み方:**
- MemAvailable > MemTotalの20%: 健全
- MemAvailable 10-20%: 注意深く監視
- MemAvailable < 10%: 危険、OOM Killerリスク

### CPU使用率

CPU時間のパーセンテージ内訳として表示:

- **user**: アプリケーションコードの実行時間
- **system**: カーネルコードの実行時間
- **idle**: 何もしていない時間
- **iowait**: I/O完了待ちでCPUがアイドルの時間
- **steal**: ハイパーバイザに取られた時間（VMのみ）

**読み方:**
- userが高い: アプリケーションがCPUバウンド
- iowaitが高い: ストレージボトルネック（CPU問題ではない）
- stealが高い: ホストがオーバーコミット、VMの移行を検討

### ネットワーク

インターフェース別トラフィック統計:

- **RX bytes / TX bytes**: 受信/送信データ量
- **RX packets / TX packets**: 受信/送信パケット数
- **RX errors / TX errors**: 受信/送信エラー（0であるべき）
- **RX drops / TX drops**: ドロップされたパケット（0であるべき）

エラーやドロップが0以外の場合、ハードウェアの問題、ドライバのバグ、またはネットワーク輻輳を示します。

### ディスク

ルートファイルシステムの使用率とI/O統計:

- **使用率 %**: ルートファイルシステムの使用割合
- **読み取り/書き込み**: 完了したI/O操作

80%を超える使用率は注意が必要、90%を超えると危険です。

## 詳細へのドリルイン

セクションを選択して `Enter` を押すと、syslenz は関連するデータソースが選択された状態でクラシックモードに切り替わります。例:

- **メモリ**を選択して Enter → `meminfo` が選択されたクラシックモードが開く
- **ネットワーク**を選択 → `net/dev` が開く
- **ロード**を選択 → `loadavg` が開く

クラシックモードからは、任意のフィールドの完全な詳細ビュー、差分ビュー、グラフにアクセスできます。`Backspace` でダッシュボードに戻ります。

## カスタマイズ

### リフレッシュ間隔

リフレッシュ間隔は `~/.config/syslenz/config.toml` で設定できます:

```toml
[general]
interval_ms = 1000  # ミリ秒 (デフォルト: 1000)
```

または、実行時に `a` で自動リフレッシュのオン/オフを切り替え、`r` で手動リフレッシュできます。

### デフォルトビュー

ダッシュボードの代わりにクラシックモードで起動するには:

```toml
[general]
default_view = "classic"
```

または `--classic` CLIフラグを使用します。

### 言語

```toml
[general]
lang = "ja"  # "en" または "ja"
```
