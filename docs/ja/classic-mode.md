## 概要

クラシックモードは「Wiresharkスタイル」のインターフェースです。左側のサイドバーに全データソースを一覧表示し、右側の詳細パネルに選択したソースのフィールドを表示します。システムを深く調査するための最も強力なビューです。

どのビューからでも `O` を押すとクラシックモードに入れます。

## サイドバーナビゲーション

サイドバーには利用可能な全データソースがアルファベット順で並んでいます（安定したソートのため `BTreeMap` を使用）。`/proc` パーサー（例: `meminfo`、`cpuinfo`、`net/tcp`）、`/sys` ソース（例: `df`、`thermal`）、ネットワークツール（例: `dns`、`conntrack`）、読み込まれたプラグイン（`plugin/` プレフィックス付き）が含まれます。

| キー | アクション |
|------|----------|
| `j` / `k` または 矢印キー上下 | ソースリストを移動 |
| `Enter` または 矢印キー右 | ソースを選択し、詳細パネルにフォーカス移動 |
| `Tab` | サイドバーとコンテンツのフォーカス切り替え |
| `/` | 検索を開始 |
| `PageUp` / `PageDown` | ページ単位でスクロール |

サイドバーにフォーカスがあるとき、ハイライト中のソースのフィールドが詳細パネルに表示されます。ソースの総数はサイドバー下部に表示されます。

## 詳細ビュー

ソースを選択してコンテンツパネルにフォーカスを切り替えると、そのソースからパースされた全フィールドが表示されます:

| 列 | 説明 |
|----|------|
| **名前** | フィールド名（例: `MemTotal`、`load1`、`rx_bytes`） |
| **値** | 型に応じた書式の現在値（バイト単位、小数2桁の浮動小数点、わかりやすい時間表記） |
| **単位** | 単位（例: `kB`、`seconds`、省略の場合あり） |
| **説明** | フィールドの説明 |

| キー | アクション |
|------|----------|
| `j` / `k` または 矢印キー上下 | フィールドをスクロール |
| `Enter` | テーブルフィールドにドリルイン（Table型の場合） |
| `Backspace` または 矢印キー左 | サイドバーに戻る |
| `d` | 差分ビューに切り替え |
| `g` | 選択フィールドのグラフビューに切り替え |
| `c` | 選択フィールドの値をクリップボードにコピー |
| `e` | 現在のスナップショットをJSONファイルにエクスポート |

### フィールドの型

syslenz は全ての値を6つの型のいずれかにパースします:

| 型 | 表示形式 | 例 |
|----|---------|-----|
| **Bytes** | わかりやすい形式 (KiB, MiB, GiB) | `15.7 GiB` |
| **Integer** | 数値 | `42` |
| **Float** | 小数2桁 | `3.14` |
| **Text** | 文字列 | `Linux 6.1.0` |
| **Duration** | 日、時間、分、秒 | `3d 14h 22m` |
| **Table** | 行数表示 | `[256 rows]` |

## テーブルドリルイン

フィールドがTable型の場合（例: `net/tcp` の接続、`processes` リスト、`mounts` エントリ）、`Enter` を押すとテーブルビューが開きます。データがカラム付きのスクロール可能なテーブルで表示されます。

| キー | アクション |
|------|----------|
| `j` / `k` または 矢印キー上下 | 行をスクロール |
| `PageUp` / `PageDown` | ページ単位でスクロール |
| `Backspace` | 詳細ビューに戻る |

テーブルは非常に大きくなることがあります（数千のTCP接続、数百のプロセスなど）。高速スクロールには `PageUp`/`PageDown` を使ってください。

## 検索

`/` を押すと検索モードに入ります。画面下部に検索入力欄が表示されます。

| キー | アクション |
|------|----------|
| 文字入力 | リアルタイムでソースリストをフィルタ |
| `Enter` | 検索を適用し、ナビゲーションに戻る |
| `Esc` | 検索をキャンセル |
| `Backspace` | 最後の文字を削除 |

検索するとサイドバーのソースリストが絞り込まれます。たとえば `net` と入力すると、「net」を含むソースだけが表示されます（例: `net/dev`、`net/tcp`、`net/udp`、`net/route`、`net/snmp`、`net/netstat`、`net/sockstat`、`net/wireless`、`net/arp`、`net/unix`）。

検索適用後はサイドバーに一致するソースだけが表示されます。`Esc` を押すか検索をクリアすると、全リストが復元されます。

## 差分ビュー

`d` を押すと差分ビューに入ります。現在のスナップショットと前回のスナップショットを比較し、変化をハイライトします:

- **追加**されたフィールド（新たに出現した値）
- **削除**されたフィールド（消えた値）
- **変更**されたフィールド（旧値と新値を並べて表示）

差分ビューはシステムのダイナミクスの把握に欠かせません。どのカウンターが増加しているか、どのメモリ値が変動しているか、どのネットワーク接続が出現・消滅したかがわかります。

| キー | アクション |
|------|----------|
| `j` / `k` | 差分エントリをスクロール |
| `PageUp` / `PageDown` | ページ単位でスクロール |
| `Backspace` | 前のビューに戻る |

**ヒント:** 自動リフレッシュ（`a`）を有効にして差分ビューに切り替えると、システムの変化をリアルタイムで観察できます。`vmstat` カウンター、`net/dev` トラフィック、`diskstats` I/O の監視に特に便利です。

## グラフビュー

数値フィールドを選択した状態で `g` を押すと、グラフビューが開きます。そのフィールドの直近60スナップショット（設定の `history_size` で変更可能）のスパークライン時系列チャートを表示します。

自動リフレッシュが有効なら、グラフはリアルタイムで更新されます。Bytes、Integer、Float、Duration のどの数値型でも動作します。

| キー | アクション |
|------|----------|
| `Backspace` | 前のビューに戻る |

**活用例:**
- メモリトレンド: `meminfo` の `MemAvailable` を選択して `g` → メモリ利用可能量の推移を観察
- CPU使用率: `stat` の `cpu_user` を選択してグラフ化
- ネットワークスループット: `net/dev` のインターフェースの `rx_bytes` を選択
- ロード追跡: `loadavg` の `load1` を選択

## エクスポートとコピー

### JSONエクスポート

`e` を押すと現在のスナップショットをJSONファイルにエクスポートします。ファイルはカレントディレクトリにタイムスタンプ付きの名前で保存されます:

```
syslenz_snapshot_1711612800.json
```

### クリップボードにコピー

`c` を押すと、選択中のフィールドの値をシステムクリップボードにコピーします。syslenz は以下のクリップボードコマンドを順に試します:

1. `xclip -selection clipboard` (X11)
2. `xsel --clipboard --input` (X11)
3. `wl-copy` (Wayland)
4. `pbcopy` (macOS)

ステータスメッセージでコピー完了を確認でき、コピーしたテキストの短縮プレビューが表示されます。
