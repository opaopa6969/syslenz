## グローバルキー

全ビュー共通のキーです。

| キー | アクション |
|------|----------|
| `q` | syslenz を終了 |
| `Esc` | syslenz を終了（または検索をキャンセル） |
| `D` | ダッシュボードに切り替え |
| `O` | クラシック（Overview）モードに切り替え |
| `W` | ウェルカムビューに切り替え |
| `X` | 自動診断ビューに切り替え |
| `C` | カテゴリガイドビューに切り替え |
| `?` | ヘルプレベル切り替え: OFF -> NORMAL -> DETAILED -> EXTRA |
| `L` | 言語切り替え (英語 <-> 日本語) |
| `a` | 自動リフレッシュのオン/オフ |
| `r` | 手動リフレッシュ（新しいスナップショットをキャプチャ） |
| `e` | 現在のスナップショットをJSONファイルにエクスポート |
| `c` | 選択した値をクリップボードにコピー |

## ダッシュボードキー

| キー | アクション |
|------|----------|
| `j` / `k` | 次/前のセクションを選択 |
| 矢印キー下/上 | 次/前のセクションを選択 |
| `Enter` | 選択セクションにドリルイン（クラシックモードを開く） |

## クラシックモードキー

### サイドバーフォーカス

| キー | アクション |
|------|----------|
| `j` / `k` | ソースリストを下/上に移動 |
| 矢印キー下/上 | ソースリストを下/上に移動 |
| `Enter` / 矢印キー右 | ソースを選択し、詳細パネルに移動 |
| `Tab` | コンテンツパネルにフォーカス切り替え |
| `/` | 検索を開始 |
| `PageUp` / `PageDown` | ページ単位でスクロール |

### コンテンツフォーカス

| キー | アクション |
|------|----------|
| `j` / `k` | フィールドを下/上にスクロール |
| 矢印キー下/上 | フィールドを下/上にスクロール |
| `Enter` / 矢印キー右 | テーブルフィールドにドリルイン |
| `Backspace` / 矢印キー左 | サイドバーに戻る |
| `Tab` | サイドバーにフォーカス切り替え |
| `d` | 差分ビューを開く |
| `g` | 選択フィールドのグラフビューを開く |
| `PageUp` / `PageDown` | ページ単位でスクロール |

## 詳細ビューキー

| キー | アクション |
|------|----------|
| `j` / `k` | フィールドをスクロール |
| 矢印キー下/上 | フィールドをスクロール |
| `Enter` | テーブルフィールドにドリルイン |
| `Backspace` | 戻る |
| `d` | 差分ビューに切り替え |
| `g` | 選択した数値フィールドのグラフを開く |
| `c` | 選択フィールドの値をコピー |

## テーブルビューキー

| キー | アクション |
|------|----------|
| `j` / `k` | 行を下/上にスクロール |
| 矢印キー下/上 | 行を下/上にスクロール |
| `PageUp` / `PageDown` | ページ単位でスクロール |
| `Backspace` | 詳細ビューに戻る |

## 差分ビューキー

| キー | アクション |
|------|----------|
| `j` / `k` | 差分エントリを下/上にスクロール |
| 矢印キー下/上 | 差分エントリを下/上にスクロール |
| `PageUp` / `PageDown` | ページ単位でスクロール |
| `Backspace` | 前のビューに戻る |

## グラフビューキー

| キー | アクション |
|------|----------|
| `Backspace` | 前のビューに戻る |

自動リフレッシュが有効なら、グラフは自動更新されます。

## 自動診断キー

| キー | アクション |
|------|----------|
| `j` / `k` | 検出結果を下/上にスクロール |
| 矢印キー下/上 | 検出結果を下/上にスクロール |
| `PageUp` / `PageDown` | ページ単位でスクロール |
| `c` | 診断結果をクリップボードにコピー |
| `Backspace` | 前のビューに戻る |

## カテゴリガイドキー

| キー | アクション |
|------|----------|
| `h` / `l` | 前/次のカテゴリに切り替え |
| 矢印キー左/右 | 前/次のカテゴリに切り替え |
| `j` / `k` | コンテンツを下/上にスクロール |
| 矢印キー下/上 | コンテンツを下/上にスクロール |
| `PageUp` / `PageDown` | ページ単位でスクロール |
| `Backspace` | 前のビューに戻る |

## 検索モードキー

クラシックモードで `/` を押すと有効になります。

| キー | アクション |
|------|----------|
| 文字入力 | ソースリストをフィルタ |
| `Enter` | 検索フィルタを適用 |
| `Esc` | 検索をキャンセル |
| `Backspace` | 最後の文字を削除 |
