# Network Deep-Dive Education

- **Status**: planned
- **DGE sessions**: 010-non-proc-metrics

## Summary

Extend education mode with deep-dive content for network metrics sourced from
`ip route`, `ip neighbor`, `ss`, `conntrack`, and DNS resolution. Currently these
sources have data parsing but limited educational annotations.

## Planned capabilities

- Educational annotations for all network data sources
- Explanation of routing tables, ARP/neighbor caches, socket states
- Guided troubleshooting flows for common network issues
- Visual connection state diagrams in web UI
