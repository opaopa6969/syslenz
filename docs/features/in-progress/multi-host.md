# Multi-Host Dashboard

- **Status**: in-progress
- **DGE sessions**: 005-g5-g6-g7-timeseries-alerts-multihost
- **Backlog**: BL-033

## Summary

Multi-host support will allow syslenz to display metrics from multiple remote hosts
in a unified dashboard view. Currently, remote monitoring supports a single host at a
time. This feature extends the architecture to aggregate snapshots from multiple
`--serve` endpoints.

## Planned capabilities

- Aggregate view across multiple remote hosts
- Per-host drill-down from unified dashboard
- Configuration of host groups
- Health-at-a-glance for fleet overview
