# Learning Paths

- **Status**: in-progress
- **DGE sessions**: 011-category-education

## Summary

Learning paths extend the education mode with structured, progressive learning sequences.
Instead of isolated per-field explanations, learning paths guide users through related
concepts in a logical order (e.g., "Understanding Memory Management" covers meminfo,
swap, pressure, and OOM in sequence).

## Planned capabilities

- Curated learning sequences across related metrics
- Progressive difficulty levels
- Completion tracking
- Integration with category-based navigation
