# Education Mode

- **Status**: completed
- **Source module**: `src/education.rs`
- **User docs**: [en](../../en/education.md) | [ja](../../ja/education.md)
- **DGE sessions**: 009-education-diagnostics, 011-category-education

## Summary

Education mode provides contextual explanations for every system metric displayed in
syslenz. When enabled, each field shows a human-readable description of what the metric
means, why it matters, and what typical values look like. Designed for Linux beginners
and students learning system internals.

## Key capabilities

- Per-field educational annotations for all parsed sources
- Category-level education with grouped explanations
- Toggle on/off without leaving the current view
- Bilingual support (English and Japanese)
