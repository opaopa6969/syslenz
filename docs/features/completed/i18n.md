## Summary

syslenz supports bilingual display (English and Japanese) for all UI labels, diagnostic
messages, and educational content. The locale is auto-detected from the system
environment or set explicitly in the configuration file.

## Key capabilities

- English and Japanese UI translations
- Automatic locale detection from `LANG` / `LC_ALL`
- Per-session locale override via config
- Bilingual user documentation (docs/en/, docs/ja/)
