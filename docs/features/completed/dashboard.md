## Summary

The Dashboard is syslenz's default view, providing a single-screen summary of system health.
Users can assess machine state in under 5 seconds. It includes AA bar graphs, sparkline
graphs, section navigation, and auto-refresh (configurable interval).

## Key capabilities

- Five curated system metric sections (CPU, Memory, Disk, Network, Load)
- AA (ASCII art) bar graphs and sparkline trend graphs
- Section navigation with keyboard shortcuts
- Drill-in to Classic Mode detail from any section
- Auto-refresh at configurable intervals
