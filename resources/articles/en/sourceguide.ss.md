# Socket Statistics (ss)

[日本語版](../ja/sourceguide.ss.md)

---

## What is it?

Socket statistics from the 'ss' command (supersedes netstat): counts of TCP sockets in each state, orphaned sockets, and UDP counts.

---

## Quick start

```sh
cat /proc/sys/block
# or use syslenz to browse with descriptions
```
