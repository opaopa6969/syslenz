# Kernel Version

[日本語版](../ja/sourceguide.version.md)

---

## What is it?

/proc/version contains the kernel version string, build information, and compiler version. Also available via `uname -a`.

---

## Quick start

```sh
cat /proc/version
# or use syslenz to browse with descriptions
```
