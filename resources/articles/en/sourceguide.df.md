# Disk Space Usage (df)

[日本語版](../ja/sourceguide.df.md)

---

## What is it?

Filesystem disk usage from statfs() system calls. Shows total, used, and available space for each mounted filesystem.

---

## Quick start

```sh
cat /proc/sys/block
# or use syslenz to browse with descriptions
```
