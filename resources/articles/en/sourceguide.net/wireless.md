# Wireless Interface Statistics

[日本語版](../ja/sourceguide.net/wireless.md)

---

## What is it?

/proc/net/wireless shows signal quality, noise, and discard counts for wireless network interfaces. Zero on wired-only servers.

---

## Quick start

```sh
cat /proc/net/wirelesys/block
# or use syslenz to browse with descriptions
```
