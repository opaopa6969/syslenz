# System Uptime

[日本語版](../ja/sourceguide.uptime.md)

---

## What is it?

/proc/uptime shows how long the system has been running and the cumulative idle time across all CPUs.

---

## Quick start

```sh
cat /proc/uptime
# or use syslenz to browse with descriptions
```
