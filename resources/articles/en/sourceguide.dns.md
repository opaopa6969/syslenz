# DNS Configuration

[日本語版](../ja/sourceguide.dns.md)

---

## What is it?

DNS resolver configuration from /etc/resolv.conf: nameservers, search domains, and resolution speed. DNS misconfiguration is a surprisingly common source of application latency.

---

## Quick start

```sh
cat /proc/dns
# or use syslenz to browse with descriptions
```
