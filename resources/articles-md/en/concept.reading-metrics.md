# Reading Metrics in syslenz

What is this?
This is the fallback article used when a metric-specific article is not available yet.

Why it matters
A metric value is meaningful only with context: trend, related fields, and workload state.

How to read
1. Start from the current value.
2. Compare with related fields.
3. Check trend in Diff/Graph.
4. Confirm user impact in Diagnostics.

Common mistakes
- Reading one field in isolation
- Ignoring units
- Ignoring time trend

Diagnostic flow
- Unexpected value -> Diff
- Persistent trend -> Graph
- User-visible impact -> Diagnostics
